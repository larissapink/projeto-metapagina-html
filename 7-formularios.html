Conceito

Os formulários permitem coletar informações fornecidas pelos usuários por meio de campos de entrada e botões.

Eles são amplamente utilizados em cadastros, pesquisas, sistemas de login e formulários de contato.

O que são Formulários?

Um formulário é uma área da página destinada à entrada de dados pelo usuário.

Os dados podem ser digitados, selecionados ou enviados por meio de diferentes tipos de campos.

Exemplo de Código

Campo de Texto

Ex: Nome, Endereço, etc.

Campo de E-mail

Utilizado para permitir que o usuário digite um endereço de e-mail.

Área de Texto

Utilizada para permitir que o usuário digite um texto mais longo, como comentários ou mensagens.

<form>
    <label for="mensagem">Mensagem:</label>
    <textarea id="mensagem" name="mensagem" rows="4" cols="50"></textarea>
</form>

Legenda:
- rows: define o número de linhas visíveis na área de texto.
- cols: define o número de colunas visíveis na área de texto.

Botão

Utilizado para permitir que o usuário execute uma ação, como enviar um formulário ou limpar os campos.

Observação: o uso de botões com funcionalidade requer um conhecimento sobre os atributos "action" e "method" do elemento <form>, o que eu não irei abordar neste tutorial.

<form action="/enviar-dados" method="POST">
  <label for="nome">Nome:</label>
  <input type="text" id="nome" name="nome">

  <label for="email">E-mail:</label>
  <input type="email" id="email" name="email">

  <!-- Botão de enviar -->
  <button type="submit">Enviar</button>

  <!-- Botão de limpar -->
  <button type="reset">Limpar</button>
</form>

Explicação das Tags

Tag <form>

O que faz: cria um formulário HTML para coleta de dados.

Tag <label>

O que faz: cria uma legenda para um elemento de entrada, ou seja, identifica e descreve um campo do formulário.

Tag <input>

O que faz: cria campos para entrada de dados no formulário.

Tag <textarea>

O que faz: cria uma área de texto para entrada de dados mais longos, como comentários ou mensagens.

Tag <button>

O que faz: cria um botão clicável que pode ser usado para enviar o formulário, limpar os campos ou executar outras ações.

Explicação dos Atributos

Atributo type

O que faz: define o tipo de campo de entrada ou botão, como texto, e-mail, senha, checkbox, radio, submit, reset, entre outros.

Atributo id

O que faz: define um identificador único para o elemento, permitindo que ele seja referenciado por outros elementos ou por scripts.

Atributo for

O que faz: associa um elemento <label> a um elemento de entrada específico, permitindo que o usuário clique no rótulo para focar no campo correspondente.

Atributo name

O que faz: define o nome do elemento, que é usado para identificar os dados enviados ao servidor quando o formulário é submetido.

Atributo value

O que faz: define o valor do elemento, que pode ser enviado ao servidor quando o formulário é submetido ou usado para definir o estado inicial de um campo.

Boas Práticas

  • Utilizar labels para identificar os campos.
  • Associar corretamente os atributos for e id.
  • Escolher o tipo de input adequado para cada situação.
  • Utilizar textos claros nos botões.
  • Organizar os campos de forma lógica.

Curiosidade

Grande parte da interação em sistemas web ocorre por meio de formulários.

Exemplo: Cadastros, pesquisas, comentários, logins e buscas utilizam formulários HTML.

Sabe aquela descrição que aparece dentro de um campo e quando clicamos no campo ele desaparece? Isso é chamado de placeholder. O placeholder é um atributo que pode ser usado para fornecer uma dica ao usuário sobre o tipo de informação esperada no campo. Ficou curioso em como usá-lo? Acesse MDN Web Docs - Placeholder para mais informações.

Erros Comuns

  • Não utilizar labels.
  • Utilizar o tipo de input incorreto (por exemplo, usar input type="text" para campos de e-mail).
  • Não associar corretamente for e id.
  • Campos sem descrição clara.
  • Botões com textos genéricos.

Resumo

Os formulários permitem coletar dados dos usuários. As tags <form>, <label>, <input>, <textarea> e <button> trabalham juntas para criar interfaces de entrada de informações de forma organizada e acessível.
