Estrutura Básica no HTML

Esta página apresenta a estrutura mínima necessária para criar um documento HTML5, explicando seus principais elementos e boas práticas.

Conceito

Toda página HTML precisa de uma estrutura básica para que o navegador consiga interpretar corretamente seu conteúdo.

Essa estrutura define o tipo do documento, informações da página e o conteúdo visível ao usuário.

O que é uma Tag?

As tags são elementos utilizados para estruturar e organizar o conteúdo de uma página HTML. Elas informam ao navegador como cada parte do conteúdo deve ser interpretada.

A maioria das tags possui uma tag de abertura e uma tag de fechamento. O conteúdo fica localizado entre elas.

Exemplo:

<p>Este é um parágrafo.</p>

Algumas tags não precisam de fechamento porque não possuem conteúdo interno. Essas tags são chamadas de tags vazias.

Exemplos:

  • <br>
  • <img>
  • <meta>

Exemplo de Código

Abaixo está um exemplo de uma página HTML com a estrutura básica, clique nas tags para ver a explicação: 

 <!DOCTYPE html>
 
 <html lang="pt-BR">
 

 <head>
 
     <meta charset="UTF-8">
     
     <meta name="description" content="Página explicando a estrutura básica de um documento HTML">
     
     <meta name="viewport" content="width=device-width, initial-scale=1.0">
     
     <title>Título da Página</title>
     
 </head>
 

 <body>
 

     <header>
         Cabeçalho
     </header>
     

     <main>
         Conteúdo principal
     </main>
     

     <footer>
         Rodapé
     </footer>
     

 </body>
 

 </html>

Explicação das Tags

Tag <!DOCTYPE html>

O que faz: informa ao navegador que o documento utiliza HTML5.

Tag <html>

O que faz: é o elemento raiz da página e contém todo o conteúdo HTML. Quando utilizado com o atributo lang, informa o idioma principal da página.

Tag <head>

O que faz: armazena informações da página que não são exibidas diretamente ao usuário.

Exemplos de elementos dentro da tag <head>:

  • Título da página
  • Metadados
  • Links para CSS
  • Scripts JavaScript

Tag <meta>

Quando utilizada com o atributo charset, define a codificação de caracteres do documento, garantindo a exibição correta de acentos e símbolos especiais.
Exemplo: á é í ó ú ç ã

Quando utilizado o atributo name e content, permite adicionar metadados à página, como descrição, palavras-chave, autor, entre outros.

Quando utilizada com o atributo name="viewport" e o content="width=device-width, initial-scale=1.0", permite adaptar a página para telas menores, como celulares e tablets.

Tag <title>

O que faz: define o texto exibido na aba do navegador.

Tag <body>

O que faz: contém todo o conteúdo da página web visível para o usuário.

Tag <header>

O que faz: representa o cabeçalho da página ou seção.

Normalmente a tag <header> contém:

  • logotipo
  • título
  • menu de navegação

Tag <main>

O que faz: representa o conteúdo principal da página.

Tag <footer>

O que faz: representa o rodapé da página ou seção.

Normalmente a tag <footer> contém:

  • direitos autorais
  • informações de contato
  • referências
  • links úteis/complementares

Comentários

Comentários são anotações inseridas no código HTML que não são exibidas na página pelo navegador. Eles servem para documentar o código e facilitar sua manutenção.

Exemplo:

<!-- Este é um comentário HTML -->

Boas Práticas

  • Utilizar a tag <!DOCTYPE html> no início do documento para definir o tipo de documento.
  • Definir o idioma da página corretamente na tag <html> para melhorar acessibilidade e SEO.
  • Incluir as tags <head> e <body> para separar as informações de metadados e o conteúdo visível.
  • Usar a tag <meta charset="UTF-8"> para compatibilidade de caracteres.
  • Adicionar a tag <meta name="viewport" content="width=device-width, initial-scale=1.0"> para tornar a página responsiva em dispositivos móveis.
  • Escolher um título curto, descritivo e relevante para a página na tag <title>.
  • Ter apenas uma tag <main> por documento.
  • Manter a indentação consistente.
  • Utilizar tags semânticas como <header>, <main> e <footer>.

Erros Comuns

  • Esquecer o DOCTYPE.
  • Esquecer o fechamento das tags.
  • Atribuir valores incorretos a atributos.
  • Fechar tags na ordem incorreta.
  • Não utilizar indentação.

Resumo

A estrutura básica de um documento HTML é formada pelas tags <!DOCTYPE>, <html>, <head> e <body>. Esses elementos garantem que o navegador interprete corretamente a página e fornecem a base para qualquer projeto web.
