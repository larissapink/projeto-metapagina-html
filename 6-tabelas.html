Conceito

As tabelas são utilizadas para organizar dados em linhas e colunas, facilitando a leitura e comparação de informações.

Elas são muito utilizadas para exibir relatórios, horários, planilhas simples e tabelas de dados.

A MDN reforça que tabelas devem ser utilizadas para representar dados tabulares e não para criar layouts de páginas, prática antiga atualmente desencorajada.

Fonte: MDN Web Docs - HTML Table Basics

O que são Tabelas?

Uma tabela é uma estrutura formada por linhas e colunas utilizada para apresentar informações relacionadas.

No HTML, as tabelas são construídas utilizando tags específicas que organizam os dados de forma hierárquica.

Exemplo de Código

Veja abaixo um exemplo de código HTML com tabelas e logo após a sua saída:

<table>
    <tr>
        <th>Tecnologia</th>
        <th>Função</th>
    </tr>

    <tr>
        <td>HTML</td>
        <td>Estrutura</td>
    </tr>

    <tr>
        <td>CSS</td>
        <td>Estilo</td>
    </tr>
</table>

Saída do código acima:

Tecnologia Função
HTML Estrutura
CSS Estilo

Observação: a tabela acima possui estilização CSS de bordas e preenchimentos para fins de melhor visualização do conteúdo.

Estrutura de uma Tabela

Apresentação Visual

<table>
│
├─ <tr>
│   ├─ <th>
│   └─ <th>
│
├─ <tr>
│   ├─ <td>
│   └─ <td>
│
└─ <tr>
    ├─ <td>
    └─ <td>

Legenda:
table → tabela
tr    → linha
th    → cabeçalho
td    → célula de dados

Explicação das Tags

Tag <table>

O que faz: cria uma tabela.

Tag <tr>

O que faz: representa uma linha da tabela.

Tag <th>

O que faz: representa uma célula de cabeçalho.

Tag <td>

O que faz: representa uma célula de dados.

Boas Práticas

  • Utilizar tabelas apenas para dados tabulares.
  • Utilizar a tag <th> para cabeçalhos.
  • Manter os dados organizados em linhas e colunas.
  • Utilizar títulos claros para os cabeçalhos.
  • Evitar tabelas excessivamente grandes ou complexas.

Curiosidade

Antigamente muitos sites utilizavam tabelas para construir o layout completo da página. Atualmente essa prática foi substituída por elementos semânticos do HTML e técnicas modernas de CSS.

Erros Comuns

  • Utilizar tabelas para criar layouts de páginas.
  • Esquecer a tag <tr>.
  • Utilizar <td> no lugar de <th> nos cabeçalhos.
  • Organizar dados em colunas incorretas.
  • Fechar tags na ordem errada.

Resumo

As tabelas permitem organizar dados em linhas e colunas. As tags <table>, <tr>, <th> e <td> trabalham em conjunto para criar tabelas estruturadas e fáceis de interpretar.
