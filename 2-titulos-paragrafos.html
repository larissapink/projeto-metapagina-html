Conceito

Títulos e parágrafos são elementos fundamentais do HTML utilizados para organizar e apresentar informações de forma clara e estruturada.

Os títulos definem a hierarquia do conteúdo, enquanto os parágrafos são utilizados para exibir blocos de texto.

O que são Títulos e Parágrafos?

Títulos

Os títulos são utilizados para identificar seções e subseções de uma página. O HTML possui seis níveis de títulos, representados pelas tags <h1> até <h6>.

Parágrafos

Os parágrafos são definidos pela tag <p> e servem para organizar blocos de texto em uma página.

Exemplo de Código

Veja abaixo um exemplo de código HTML com títulos e parágrafos e logo após a sua saída:

<p>Aprenda os fundamentos do HTML.</p>

<hr>

<h2>Subtítulos</h2>

<p>
Os títulos ajudam a organizar o conteúdo.
</p>

<h3>Hierarquia</h3>

<p>
Os níveis dos títulos indicam a importância de cada seção.
</p><br>

Hierarquia dos Títulos

A MDN enfatiza a importância da hierarquia correta dos títulos para acessibilidade e organização do conteúdo.

H1 → Título Principal

 └─ H2 → Seção

      └─ H3 → Subseção

Os títulos devem seguir uma ordem lógica para representar a estrutura do conteúdo.

Explicação das Tags

Tag <h1> até <h6>

O que faz: define títulos e subtítulos em diferentes níveis de importância.

O W3Schools destaca que os títulos devem ser usados para estruturar o conteúdo e não apenas para estilizar o texto.

Fonte: W3Schools - HTML Headings

Tag <p>

O que faz: define um parágrafo de texto.

Tag <br>

O que faz: insere uma quebra de linha sem criar um novo parágrafo.

Tag <hr>

O que faz: representa uma mudança de assunto ou separação temática entre conteúdos. Os navegadores normalmente a exibem como uma linha horizontal.
A própria W3Schools destaca o <hr> como uma separação temática do conteúdo.

Boas Práticas

  • Utilizar apenas um <h1> como título principal da página.
  • Manter a hierarquia correta dos títulos.
  • Usar <p> para blocos de texto.
  • Utilizar <br> apenas para pequenas quebras de linha.
  • Utilizar <hr> para indicar uma mudança de assunto ou separação temática.
  • Não utilizar títulos apenas para aumentar o tamanho do texto, essa funcionalidade deve ser controlada por estilos CSS.
    A MDN e a W3Schools reforçam que títulos devem representar a estrutura do documento e não ser usados apenas por motivos visuais.

Erros Comuns

  • Utilizar vários <h1> sem necessidade.
  • Pular níveis de títulos, como passar de <h1> para <h4>.
  • Utilizar <br> para criar espaçamentos grandes.
  • Escrever textos longos sem utilizar parágrafos.
  • Usar títulos apenas para deixar o texto maior.

Resumo

As tags <h1> até <h6> são utilizadas para criar títulos e subtítulos, enquanto a tag <p> é utilizada para criar parágrafos. As tags <br> e <hr> complementam a organização do conteúdo, contribuindo para uma melhor estrutura e legibilidade da página.
