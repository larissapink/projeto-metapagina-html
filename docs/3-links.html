Conceito

Os links são elementos essenciais da Web, pois permitem conectar páginas, documentos, arquivos e recursos na internet.

No HTML, os links são criados utilizando a tag <a>, também conhecida como âncora.

Exemplo de link externo para o Google:
Clique em Visitar o Google e você será redirecionado para o site do Google.

O que são Links?

Um link é um elemento clicável que direciona o usuário para outra página, seção ou recurso.

Exemplo de Código

Veja abaixo um exemplo de código HTML com links e logo após a sua saída:

<a href="index.html">Página Principal</a>

<a href="https://developer.mozilla.org" target="_blank">MDN Web Docs</a>

<a href="#referencias">Ir para Referências</a>

Observação: Para correta relação entre os links da seção da página, utilize os IDs correspondentes a cada seção.

Exemplo:
<a href="#referencias-links">Ir para Referências</a>

- irá direcionar para a seção de "Referências" da página se o ID estiver corretamente definido -
<section id="referencias-links">
<h2>Referências</h2>
</section>

Tipos de Links

Link Relativo

Utilizado para navegar entre páginas do próprio projeto.

Exemplo:
<a href="2-titulos-paragrafos.html">Títulos e Parágrafos no HTML</a>

Link Absoluto

Utilizado para acessar páginas externas por meio de uma URL completa.

Exemplo:
<a href="https://developer.mozilla.org">MDN Web Docs</a>

Link de Âncora

Utilizado para navegar para uma seção da mesma página.

Exemplo:
<a href="#boas-praticas-links">Ir para Boas Práticas</a>

Explicação das Tags e Atributos

Tag <a>

O que faz: cria um link clicável.

Atributo href=" "

O que faz: define o destino do link.

Exemplo:
<a href="https://developer.mozilla.org">MDN Web Docs</a>

Atributo target=" "

O que faz: define onde o link será aberto.

Destaque para os valores mais comuns:

  • _blank: abre o link em uma nova aba ou janela.
  • _self: abre o link na mesma aba ou janela atual. Este é o comportamento padrão.

Atributo rel=" "

O que faz: adiciona informações sobre a relação entre a página atual e o destino do link.

Curiosidade: Tag <link>

Apesar do nome parecido, a tag <link> possui uma finalidade diferente da tag <a>.

Ela é utilizada para relacionar recursos externos ao documento HTML, como folhas de estilo CSS.

Exemplo: 

<link rel="stylesheet" href="style.css">

Você aprenderá mais sobre essa tag quando começar a estudar CSS.

Boas Práticas

  • Utilizar textos descritivos para os links.
  • Usar links relativos para páginas internas do projeto.
  • Utilizar target="_blank" apenas quando realmente necessário.
  • Utilizar rel="noopener noreferrer" em links externos que abrem em nova guia. (Ajuda a evitar problemas de segurança ao abrir links externos em novas abas)
  • Verificar periodicamente se os links continuam funcionando.

Erros Comuns

  • Utilizar textos genéricos como "clique aqui".
  • Esquecer o atributo href.
  • Criar links quebrados.
  • Utilizar URLs incorretas.
  • Abrir todos os links em novas abas desnecessariamente.

Resumo

A tag <a> é utilizada para criar links em HTML. Por meio do atributo href é possível direcionar o usuário para páginas internas, páginas externas ou seções da própria página.
