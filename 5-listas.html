Conceito

As listas são utilizadas para organizar informações relacionadas de forma clara e estruturada.

Elas são muito utilizadas em menus de navegação, tutoriais, documentações e listas de tarefas.

O que são Listas?

Uma lista é um conjunto de itens relacionados apresentados de forma organizada.

O HTML oferece listas ordenadas, não ordenadas e listas aninhadas.

Exemplo de Código

Veja abaixo um exemplo de código HTML com listas e logo após a sua saída:

<p>Lista não ordenada</p>

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

<p>Lista ordenada</p>

<ol>
    <li>Instalar VS Code</li>
    <li>Criar arquivo HTML</li>
    <li>Abrir no navegador</li>
</ol>

Saída do código acima:

Lista não ordenada

  • HTML
  • CSS
  • JavaScript

Lista ordenada

  1. Instalar VS Code
  2. Criar arquivo HTML
  3. Abrir no navegador

Tipos de Listas

Lista não ordenada

Utilizada quando a ordem dos itens não é importante.

Lista ordenada

Utilizada quando a sequência dos itens é importante.

Lista Aninhada

Uma lista aninhada é uma lista inserida dentro de outra lista.

Exemplo: 

<ul>
    <li>Front-end
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
    <li>Back-end
        <ul>
            <li>API</li>
            <li>Banco de Dados</li>
        </ul>
    </li>
</ul>

Saída do código acima:

  • Front-end
    • HTML
    • CSS
  • Back-end
    • API
    • Banco de Dados

Explicação das Tags

Tag <ul>

O que faz: cria uma lista não ordenada.

Tag <ol>

O que faz: cria uma lista ordenada.

Tag <li>

O que faz: representa um item de lista.

Observação: a tag <li> pode ser utilizada tanto dentro de uma tag <ul> quanto dentro de uma tag <ol>.

Boas Práticas

  • Utilizar listas quando os itens estiverem relacionados.
  • Escolher ul ou ol conforme a necessidade.
  • Manter a estrutura hierárquica organizada.
  • Utilizar listas aninhadas com moderação.
  • Evitar usar parágrafos para simular listas.

Curiosidade

Menus de navegação em sites modernos frequentemente são construídos usando listas HTML combinadas com CSS.

Exemplo: 

<ul>
    <li>Início</li>
    <li>Sobre</li>
    <li>Contato</li>
</ul>

  • Início
  • Sobre
  • Contato

Erros Comuns

  • Inserir tag li fora de uma lista.
  • Utilizar ol quando a ordem não importa.
  • Utilizar ul quando a ordem é importante.
  • Criar listas excessivamente profundas.
  • Fechar as tags incorretamente.

Resumo

As listas permitem organizar informações de forma clara e estruturada. O HTML oferece listas não ordenadas <ul>, listas ordenadas <ol> e itens de lista <li>, que podem ser combinados para criar estruturas hierárquicas.
