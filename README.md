# Metapágina Didática HTML

Este projeto consiste em um portfólio desenvolvido em **HTML** e foi organizado como uma metapágina de estudos com conteúdos visuais e progressivos sobre fundamentos de desenvolvimento web. O objetivo principal é demonstrar na prática como estou aplicando os conceitos e conhecimentos adquiridos durante a graduação em projetos.

## 🌐 Acesso ao projeto
[Metapágina Didática HTML](https://larissapink.github.io/projeto-metapagina-html/)

## Tecnologias utilizadas

- HTML5
- CSS3
- Visual Studio Code
- Git e GitHub

Como estudante em início de carreira e em busca de estágio na área de TI, desenvolvi este projeto para demonstrar organização, documentação, estruturação de código, constância e aplicação prática dos conteúdos acadêmicos.
