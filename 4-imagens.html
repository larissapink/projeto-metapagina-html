Conceito

As imagens ajudam a tornar uma página mais visual, informativa e atrativa para os usuários.

No HTML, as imagens são inseridas utilizando a tag <img>.

O que são Imagens no HTML?

Uma imagem é um recurso visual incorporado à página por meio da tag <img>.

Ela pode ser utilizada para ilustrar conteúdos, apresentar produtos, exibir logotipos e complementar informações textuais.

Exemplo de Código

Veja abaixo um exemplo de código HTML com imagens e logo após a sua saída:

<img src="html5.png" alt="Logotipo do HTML5" width="100" height="100">

src    → caminho da imagem
alt    → descrição textual
width  → largura da imagem
height → altura da imagem

Explicação das Tags e Atributos

Tag <img>

O que faz: incorpora uma imagem ao documento HTML.

Atributo src=""

O que faz: define o caminho da imagem.

Atributo alt=""

O que faz: fornece um texto alternativo para a imagem caso ela não possa ser carregada.

Exemplo:
<img src="html5-imagem.png" alt="Texto alternativo para a imagem: Logotipo do HTML5">

Como o arquivo não existe, o navegador exibirá o texto alternativo.

Atributo width=""

O que faz: define a largura da imagem.

Atributo height=""

O que faz: define a altura da imagem.

Formatos de Imagem Mais Comuns

JPG (JPEG)

Ideal para fotografias e imagens com muitas cores.

PNG

Ideal para imagens com fundo transparente.

SVG

Ideal para logotipos e ícones, pois não perde qualidade ao ser redimensionado.

WebP

Formato moderno que oferece boa qualidade com tamanho reduzido.

Boas Práticas

  • Utilizar sempre o atributo alt.
  • Dar nomes descritivos aos arquivos de imagem.
  • Utilizar formatos adequados para cada situação.
  • Manter imagens organizadas em uma pasta específica.
  • Definir width e height quando apropriado.

Curiosidade

A tag <img> é uma tag vazia, ou seja, ela não possui conteúdo interno e não necessita de fechamento.

Erros Comuns

  • Esquecer o atributo alt.
  • Utilizar caminhos incorretos no src.
  • Usar imagens muito pesadas.
  • Organizar imagens em locais desnecessariamente complexos.
  • Utilizar o formato errado para a finalidade da imagem.
  • Erros de digitação na aplicação do código.

Resumo

A tag <img> é utilizada para inserir imagens em páginas HTML. Os atributos src e alt são fundamentais para o funcionamento correto e para a acessibilidade da imagem, enquanto width e height permitem definir suas dimensões.
